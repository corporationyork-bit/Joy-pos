# JOY POS

Aplikasi Point of Sale (POS) berbasis web (PWA) untuk transaksi kasir, manajemen stok, dan laporan penjualan.

## Struktur File
- `index.html` — Halaman awal & navigasi
- `kasir.html` — Terminal kasir (transaksi & struk)
- `admin.html` — Dashboard admin (produk, stok, outlet, karyawan, transaksi, pengaturan)
- `manifest.json` & `sw.js` — Konfigurasi PWA & cache

## Cara Pakai
1. Buka halaman utama atau langsung ke `kasir.html` / `admin.html`.
2. Bisa di-install ke layar utama lewat menu **Add to Home Screen** di browser.
3. Atur outlet, karyawan, PIN, dan produk lewat menu **Admin Dashboard**.
